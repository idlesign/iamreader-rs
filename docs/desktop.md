# Запуск и устройство приложения

## Требования и установка

Для сборки нужен Rust 1.95+, C/C++ toolchain, CMake, Clang и системные библиотеки из `dev_bootstrap.sh`.
GUI рассчитан на Linux с X11/Wayland и OpenGL; запись и воспроизведение используют системный аудиобэкенд.
Готовую версию можно распаковать из [GitHub Releases](https://github.com/idlesign/iamreader-rs/releases/); сборка из исходников — `cargo build --locked --release`.

Whisper и denoise необязательны. Модели загружаются через `get_models.sh` и ищутся
в каталоге `models/` рядом с исполняемым файлом. `dev_bootstrap.sh` также загружает их.

## Обычный запуск

```bash
cargo run --locked --bin iamreader -- /path/to/iamreader.json
```

Без пути используется `iamreader.json` в текущем каталоге. GUI на egui/eframe 0.37
использует Glow, а не WebView. Slint и отдельного `iamreader-egui` больше нет.
Запуск GUI включает мониторинг уровня микрофона; headless сам его не включает.

Компоновка главного окна сохранена: меню и режимы A/U/I, данные книги и главы,
два графика рядом, подсказки, поиск и таблица отрывков с итогами внизу.
Кнопка `Compile F8` запускает сборку книги, `Shortcuts F1` открывает справку
по клавишам (в узком окне — `F1`). Запись, воспроизведение и удаление отрывка
управляются горячими клавишами; двойной щелчок по отрывку открывает его настройки.

## Без GUI

Основной исполняемый файл поддерживает `--headless`. Чтобы не собирать и не включать
GUI-зависимости вообще, используйте отдельную точку входа:

```bash
cargo build --locked --release --no-default-features --bin iamreader-headless
target/release/iamreader-headless /path/to/iamreader.json --fifo /tmp/iamreader.fifo
```

Процесс ожидает команды через FIFO или завершение по Ctrl+C. Запись и воспроизведение
открывают устройства только по соответствующим командам. Например, `compile` собирает
проект без микрофона, а `shutdown` завершает процесс:

```bash
printf 'compile\n' > /tmp/iamreader.fifo
printf 'shutdown\n' > /tmp/iamreader.fifo
```

Справка работает без открытия проекта, моделей и аудиоустройств:

```bash
target/release/iamreader --help
target/release/iamreader-headless --help
```

## Архитектура

- `crates/engine` — независимый `iamreader-engine`: проект, запись, обработка и экспорт.
- `src/egui_ui` — интерфейс и его черновики, фокус, диалоги и прокрутка.
- `src/cli.rs`, `src/fifo.rs` — запуск и транспорт команд.

GUI и FIFO обращаются к одному `EngineHandle`. Команды получают request ID и отдельное
подтверждение; строки адресуются стабильным путём, а не текущим местом в списке.
GUI читает версионные снимки и ограниченные очереди изменений. Уведомления будят egui
по изменениям, без таймера перерисовки в простое; live-телеметрия объединяется.

GUI не владеет аудиоустройствами и не меняет проект напрямую. Формат `iamreader.json`,
синтаксис FIFO и нумерация его команд сохранены. Для `m_add`, `m_del`, `m_set` используются
номера в порядке создания, для `trans` — обратный порядок отображения, начиная с 1.

## Проверки и архив

```bash
cargo test --locked --workspace -j 4
cargo test --locked --workspace --no-default-features -j 4
./bundle.sh
```

Обычные тесты используют синтетическое аудио и временные проекты. Они не включают
микрофон, не загружают настоящие модели и не открывают окно в пользовательском сеансе.
Архив содержит основной `iamreader`, лицензию, README и скрипт загрузки моделей;
сами модели в него не входят.
